## Before you begin

Slash-command visibility is controlled through Discord **Server Settings → Integrations**. A visible command can still require a manager role, reviewer role, ownership, or active membership. Panel buttons have their own eligibility checks.

A private response is visible only to its user in Discord; it is not a direct message. Application and ticket channels are separate conversations with their configured participants. Re-gear and specialisation evidence is posted in the configured feature channel, where its viewers can see it.

For exact options, use the [command reference]({{ '/reference/' | relative_url }}).
