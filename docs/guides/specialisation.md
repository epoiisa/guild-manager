# Weapon Specialisation

Guild Manager records confirmed screenshot proof for an Albion Online weapon at level 100 or an Albion Online weapon tree at level 800.

## Submit proof

1. Open the Weapon Specialisation panel.
2. Click **Weapon 100** or **Tree 800**.
3. Select your eligible character and tree; for Weapon 100, also select the weapon.
4. Upload exactly one image in **Proof Screenshot** and submit.

`/weapon 100` and `/weapon 800` provide equivalent command entry points. Your selected character must be registered to you and eligible through active member-group membership. Already confirmed or overlapping Pending targets are unavailable for duplicate submission. Server catalogue exclusions can also remove targets from the selector.

Setup is private, but submitted proof is visible in the configured specialisation channel. Use **My Specialisations** or `/weapons` to view your confirmed records; submitting proof alone does not confirm it.

## Review requests

A configured Weapon Specialisation manager or Discord Administrator can open **Pending Requests**, use `/specialisation requests`, and review the proof. `/specialisation review` records the selected response. Confirmed records are available through `/specialisation list`, optionally filtered to a character.

Authority applies across all Albion Online servers within the Discord server. A manager's personal report still shows their own records; use management reports for other characters.

## Correct records and configure the catalogue

Use `/specialisation add` for an audited manual addition and `/specialisation remove` to remove an active record. The level must match the kind: 100 for a weapon, 800 for a tree.

`/specialisation catalogue edit` opens the enabled-name configuration; `/specialisation catalogue reset` presents the full catalogue for review before restoration. These are server configuration actions, so review the effect on available submission choices.

Records follow the stable Albion Online character identity within this Discord server. `/kick` preserves them while removing user access; an officer reconnection does not restore former manager authority.
