# Documentation

> **Disclaimer**
> This documentation was generated by GPT 6.1 Sol and I have not reviewed it yet. — Epoiisa

Guild Manager is a self-hosted Discord bot for Albion Online guilds and communities. It brings character registration, membership, applications, tickets, parties, giveaways, character accounts, re-gears, and weapon specialisation into your Discord server.

These docs describe **0.1.0-alpha.1**, an alpha prerelease. Commands and database schemas may change between releases. Check the release notes before updating.

## Start here

- **[Configure your Discord server]({{ '/getting-started/administrator/' | relative_url }})** — activate the bot, configure membership and channels, and grant command access.
- **[Use Guild Manager]({{ '/getting-started/member/' | relative_url }})** — register your characters and find the features available to you.
- **[Host your own bot]({{ '/self-hosting/' | relative_url }})** — install Guild Manager with your own Discord application and PostgreSQL database.

## Availability, licence, and support

The public release is available for independent self-hosting. Public access to the maintainer's hosted instance is not currently offered. Self-hosting is free; your infrastructure may incur costs.

Guild Manager uses the [MIT licence](https://github.com/epoiisa/guild-manager/blob/main/LICENSE). Third-party dependencies retain their own licences. The project is developed almost exclusively using AI tools under the maintainer's direction. Operators should review the code and test in their own Discord server before relying on it.

Use [GitHub Issues](https://github.com/epoiisa/guild-manager/issues) to report reproducible problems and [Discussions](https://github.com/epoiisa/guild-manager/discussions) for questions. Remove credentials and personal information from anything you share. Support and contributions are at the maintainer's discretion.

Guild Manager is independent and is not affiliated with or endorsed by Discord or the makers of Albion Online.
